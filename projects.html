01
Industrial IoTModbusWeb

Sea Water Purifier Monitoring

During my Tech Mahindra project internship, I worked with data flowing from industrial equipment through a MOXA gateway. My work included decoding Modbus ASCII frames, validating LRC values, mapping registers, and helping present measurements through a responsive monitoring dashboard.

What I learned

Hardware-to-software systems fail at boundaries. I learned to treat protocol parsing, data validation, and interface responsiveness as one connected user experience.

02
Edge AIOpenCVJetson Nano

Jetson Nano Vision System

This work explored object detection and number-plate recognition on an embedded GPU platform. I worked through camera capture, OpenCV setup, CUDA-related checks, and the practical constraints of deploying computer vision outside a laptop environment.

What I learned

A model is only one part of an AI product. Camera I/O, hardware compatibility, latency, networking, and deployment decisions determine whether the system works.

03

Student Management System

I developed a CRUD-based student application with an Express API, MySQL persistence, authentication, and a responsive browser interface. The project evolved from basic routes into a more complete system with protected operations and deployment testing.

Building a full flow made the connections between UI state, API design, database constraints, and authentication much clearer than studying each topic in isolation.

04
Machine LearningCNNEvaluation

Pneumonia Detection

I compared several convolutional neural network approaches for chest X-ray classification, including transfer-learning models and a majority-vote ensemble. The evaluation showed that the ensemble was not automatically better than the strongest individual architecture.

What I learned

More models do not guarantee a better result. Careful evaluation and understanding error patterns matter more than adding complexity for its own sake.

05
Python · PyTorch

Traffic Signal Control

Built a custom intersection simulator with DQN, Double DQN, Dueling DQN, tabular Q-Learning, SARSA, and a fixed-time baseline. Initial learned policies underperformed, prompting a redesign of the reward around queue length, a minimum-green constraint, and a phase-duration state feature.

Evaluation

After the redesign, deep-RL agents reduced average waiting time by roughly 78% against the fixed-time baseline over 20 evaluation episodes, while maintaining throughput. This is a result from the project’s simulator, not a claim about real-world traffic.

06
IoT · Embedded C

Smart Water Management

Built an IoT system to monitor water levels, usage, and quality in real time. Automated control and a connected mobile application supported remote monitoring and timely alerts.

Purpose

Help users respond to changing water conditions and support proactive maintenance through connected sensing and control.

07
IoT · Embedded C

Food Quality Monitoring

Designed and deployed a sensor-based system to monitor food-quality parameters, including temperature and humidity. A mobile notification system alerted users when readings deviated from predefined thresholds.

Purpose

Make changing storage conditions visible through measurements and threshold-based alerts. These environmental readings support monitoring; they do not establish that food is safe to consume.

08
Python · Scikit-learn · Pinecone

Internal Project Recommender

During the Tech Mahindra internship, developed an internal project recommender using Python, Scikit-learn, and Pinecone vector similarity search. The system helped colleagues discover relevant work across a collection of more than 300 documents.

Reported outcome

The résumé reports a 40% reduction in search time. The work was delivered with a six-member cross-functional team; the internal data and application are not presented as a public demo.
